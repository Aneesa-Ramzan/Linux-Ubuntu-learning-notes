
# Linux Learning Notes

My hands-on learning journey with Ubuntu Linux.

## Topics

- Basic Linux commands
- File and directory management
- Users and groups
- File permissions
- Processes and system services
- Task scheduling with cron
- Networking fundamentals

## Purpose

This repository documents commands I have practised, explains what they do, and records practical exercises as I strengthen my Linux and cybersecurity foundations.

## Learning Approach

- Practise commands in an Ubuntu virtual machine.
- Explain each command in my own words.
- Record useful examples and troubleshooting lessons.
- Add new topics as I complete them.
